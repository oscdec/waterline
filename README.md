# Waterline

A calm to-do list. Only today's few sit above the surface; everything else rests in the reservoir below.

## Put it on your phone with GitHub Pages

1. Create a new GitHub repository (for example `waterline`) and upload every file in this folder to it.
2. In the repository, open Settings → Pages. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. After a minute, open `https://<your-username>.github.io/waterline/` on your phone.
4. iPhone: in Safari, tap Share → Add to Home Screen. Android: in Chrome, tap the menu → Add to Home screen.

## Good to know

- Your list is stored only on the device, in the browser's storage. Use Settings → Save a backup now and then.
- A new day starts at 4am. Unfinished tasks return to the top of the reservoir; finished ones are cleared.
- To ship an update, upload the changed files and bump the version number in `index.html` and `sw.js` (for example 1.21 to 1.22).
